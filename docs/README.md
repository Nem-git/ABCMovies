# ABCMovies docs

Product specification for the ABCMovies rewrite. These docs describe *what* the product is and *why*; durable decisions live in [`../decisions/`](../decisions/), and work is tracked in the GitHub project.

## Reading order

1. [VISION.md](VISION.md) — what the product is, goals, non-goals.
2. [REQUIREMENTS.md](REQUIREMENTS.md) — capabilities with intent and acceptance.
3. [PRINCIPLES.md](PRINCIPLES.md) — non-negotiable constraints and non-binding ideas.
4. [GLOSSARY.md](GLOSSARY.md) — shared terms.
5. [JOURNEYS.md](JOURNEYS.md) — key user/operator flows and failure states.
6. [QUALITY.md](QUALITY.md) — how work is verified and when it is done.
7. [SECURITY.md](SECURITY.md) — security/privacy baseline.
8. [OPERATIONS.md](OPERATIONS.md) — install/upgrade/backup/health expectations (product level).

Concrete technical choices live in `decisions/tech/`, not in product docs.
