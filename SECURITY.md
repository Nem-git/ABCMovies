# Security

## Reporting

Please report security vulnerabilities privately to the maintainers. Do not open a public issue for exploitable vulnerabilities until a fix or mitigation is available.

If no private reporting channel is configured yet, open a minimal issue requesting a private contact path without including exploit details.

## Scope notes

ABCMovies is a self-hosted media hub that may handle user-supplied source credentials/session material and access-sharing data. Security-sensitive areas include authentication, authorization, secret storage, logging, connector behavior, and sharing/revocation.
